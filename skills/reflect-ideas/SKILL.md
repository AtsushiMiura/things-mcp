name: reflect-ideas
description: Use when the user explicitly asks to reflect a discussion in Things, e.g. 「Thingsに反映して」. Reconcile ideas with an existing Things project.
---

「Thingsに反映して」と依頼された区切りで、その議論のアイディアを整理する。
会話の途中で自動保存しない。採用や着手が決まった仕事はLinearの対象として分ける。
この依頼だけでLinearに書き込まない。

1. 会話から保存先の既存プロジェクトと議題を特定する。Thingsで候補を照合し、保存先が複数考えられる場合だけ利用者に確認する。
2. 対象プロジェクトの見出しとTo-doを確認する。ページが分かれていれば続きも確認する。同じ議題の見出しを再利用し、新設が必要なら add_heading にプロジェクトIDと見出し名を渡す。
3. 各案を同じプロジェクト・見出し内のID、件名、メモで照合する。既存案なら変更のある部分だけ更新する。同名で判別できない項目は確認する。新しい案だけTo-doにして、議論の要点をメモに、未決の論点をチェックリストに置く。既存のメモや済んだチェック項目を保持する。
4. 書き込み後に対象を読み返す。応答が途切れたら再作成の前に結果を確認する。追加・更新したものと、判断待ちのものを簡潔に報告する。
